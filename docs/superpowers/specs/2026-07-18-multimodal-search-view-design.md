# 多模态检索页面精简设计

## 目标

将多模态知识库页面中的检索能力收敛为一个清晰的“多模态检索”页签。删除顶部“多模态知识库工作台”标题区和“远端问答”页签，检索结果展示参照远端 Vue 页面，但继续使用当前项目的 Ant Design Vue 组件和视觉体系。

## 页面结构

- 页面最外层直接从主页签开始，不再显示工作台标题、副标题或装饰图标。
- 原“智能搜索”页签改名为“多模态检索”，继续调用 `POST /index/search`。
- 检索条件采用紧凑的响应式表单：
  - 问题输入占完整一行。
  - 知识库、搜索范围、文件和召回数量位于第二行。
  - 搜索按钮右对齐。
- 结果区域独立成一个全宽面板，标题展示结果数量。
- 每条结果使用可折叠项：
  - 第一条结果默认展开。
  - 折叠标题显示序号、匹配分数、来源文件和内容类型。
  - 展开内容显示 Markdown 正文、表格和检索命中的图片。
  - 底部“出处”展示文件、页码、类型、章节和图片名称。
- 无结果时显示明确空状态；请求期间使用现有按钮加载状态。

## 数据处理

- 请求参数保持 `{ kbId, query, k, fileId }`，不调用 `/query` 或 `/chat`。
- 新增独立的搜索结果工具，负责安全解析 `source` JSON，并生成统一的来源字段。
- 图片仍通过 `/pdf/images` 代理地址加载；结果正文中的图片使用懒加载和异步解码，避免一次性阻塞页面。
- 无效 `source`、缺失页码或缺失图片名称时只隐藏对应出处字段，不影响正文展示。

## 删除范围

- 删除 `remoteQa` 页签模板。
- 删除 `remoteQaMode`、`remoteQaKbId`、`remoteQaFileId`、`remoteQaFiles`、`remoteQaSessionId`、`remoteQaInput`、`remoteQaResponse`、`remoteQaLoading`。
- 删除 `/query`、`/chat` 和 `/chat/clear` 对应的页面事件处理及监听。
- 删除仅供远端问答使用的样式。
- API 封装暂时保留，避免影响项目其他调用方；本页面不再引用这些接口。

## 验证

- 工具单元测试覆盖有效 JSON、无效 JSON、图片结果和普通文本结果。
- 页面结构测试确认顶部标题区和远端问答已删除，并确认“多模态检索”页签存在。
- Vite 生产构建必须成功。
- 浏览器检查桌面与窄屏：表单不溢出、折叠结果可操作、命中图片可显示、页面无明显重叠。
